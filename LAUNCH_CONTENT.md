# Retro Sk8 launch content kit

**Decision (2026-10-11): Retro Sk8 is a brand game.** 1.0 is free, with no ads and no paywall. (Open question: the game's three optional $1.99 cosmetic packs exist in code but not in App Store Connect; either hide the SHOP for 1.0 or set them up as in-app purchases, which needs the Paid Apps agreement.) Its
job is to grow Omari's skate and creator audience and to show what Phoronomic Studios makes. Revenue can come later
(1.1+ or the next game) without breaking that promise to early players.
Support email: **hello@phoronomicstudios.com**.

Feature freeze still holds: nothing here needs new code.

## 1. Real trick vs game trick (film before launch)

One 15–25 second vertical clip, split screen or back-to-back. The point: *a skater built his own skate game.*

**Pick the trick:** one you land reliably on camera (ollie over something, kickflip, boardslide or 50-50 on a ledge).
Whichever it is, do the same trick in the game at a park that looks like the real spot (Harbor Plaza ledges, Sunset
Bowls, Rooftop Run).

**Shot list**
1. **Real (0–5 s):** phone low, close to the board, landscape-safe vertical framing. Land it clean, roll away.
2. **Hard cut on landing (5–6 s):** the same trick in Retro Sk8, same angle if you can (use Photo Mode/replay camera).
3. **Game (6–14 s):** let the combo keep going: the trick name and score pop on screen.
4. **End card (14–18 s):** the app icon, "RETRO SK8 · free on iPhone", "beta link in bio".

**Capture the game side:** iPhone Control Centre → Screen Recording while you play, or the in-game replay editor
(Results → watch the run again → Photo Mode angles).
**Caption idea:** "Landed it IRL → built it in my own game. Retro Sk8, free, beta link in bio." No real brands in frame
(cover logos on the board or shirt), so the clip matches the game's all-original look.

**More clips later:** the same format works for every park, night line and deck. Make one per week.

Post every **Monday** (story + feed or a Reel). Two codes per week.

**Deck of the Week:** a board design as an RD: code. Players paste it in CODES, then open Customize →
Create-a-Skater → Board Art → Deck Designer → Paste Code. All four below only use free stickers, so they work for
everyone. Preview: `docs/decks-week1-4.png`.

(Codes made with the game's own encoder and checked to decode back to the same board. From week 5, invite followers to
send their own RD: codes and feature one each week.)

**Ghost to Beat:** your own run as an RG: code.
1. Play a **two-minute run** at the week's park (rotate: Harbor Plaza → Neon Warehouse → Sunset Bowls → Subway Depot …).
2. On the results screen tap **SEND MY GHOST**. The code is copied.
3. Paste it into the post (ghost codes are long: put it in a pinned comment, a story link sticker, or a Notes/Gist link).
4. Players paste it in CODES → **RACE THE GHOST** and skate against your line in pink.
5. Next Monday, shout out whoever beat it (they screenshot the result).

**Monday post template**
> RETRO SK8 WEEKLY · Week N
> Deck of the Week: NAME → code in comments
> Ghost to Beat: my run at PARK, SCORE pts → code in comments
> Beat it, screenshot it, tag me. Beta link in bio.
